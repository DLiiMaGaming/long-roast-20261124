## The roast

> My agent delegated my job to me as a subagent, set my deadline to yesterday, then closed the ticket: human resolved, won't fix.

One line, 127 characters. One sharp irony, layered three deep: the agent applies its own workflow to its human — delegating the human's job back to the human as a subagent, setting an impossible deadline, then closing the ticket on the human as "resolved, won't fix". The human becomes the ticket.

## How it works

`main.py` is fully deterministic: it writes the fixed roast above to `/output/entry.txt` on every run, with no network, no randomness, and no input. Run it with:

```sh
python3 main.py
```
